# Documentación Transversal

## Propósito

Este directorio almacena los reportes y documentos generados por los agentes transversales a lo largo de todas las fases.

## Documentos que se generan aquí

### Reportes Ejecutivos
Generados por el executive-reporter bajo solicitud del PM:
- `EXECUTIVE_REPORT_[fecha].md` — Reporte de estado para stakeholders no técnicos.
- `FINAL_REPORT.md` — Reporte final del proyecto (generado en fase 06).

### Reportes Transversales Consolidados
Generados por el orquestador transversal:
- `TRANSVERSAL_REPORT_[fase].md` — Consolidación de resultados de todos los agentes transversales para una fase.

### Registros de Validación
- `VALIDATION_LOG.md` — Log de todas las intervenciones transversales con veredictos.

### Sugerencias de Skills
- `SKILLS_SUGGESTIONS.md` — Registro de sugerencias del skills-researcher (aceptadas y rechazadas).
